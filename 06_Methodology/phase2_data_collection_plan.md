# Phase 2 — Socioeconomic Data Expansion (planned, not yet executed)
Prepared: November 21, 2026

## Priority categories
1. Age distribution; age categories and denominator (Census).
2. Educational attainment; age 25+ universe and comparability.
3. Household income and poverty; inflation-adjusted dollar basis and poverty-measure limitations.
4. Employment and labor force participation; civilian/noninstitutional definitions.
5. Housing, household characteristics; housing/household universes.
6. Federal expenditures, grants, and obligations; distinguish obligations from outlays.

## Acquisition rules
Use official source files; save originals intact in 01_Government_Sources. Maintain separate source-year, update-date and universe fields. For the four Island Areas use 2020 Island Areas Census demographic profiles and detailed cross tabulations; for DC and Puerto Rico use comparable 2020 Decennial / ACS / PRCS sources only if variables, universe, and timing align. Record missing or not-collected values as missing, never as 0.

## Specific known limitations
Guam detailed social/economic tables may exclude U.S. military installation households/populations, whereas the total P1 census population includes them.
American Samoa social/economic tables may exclude the group quarters population.
Island Areas data differ from ACS/PRCS; avoid unqualified tests or ranks comparing non-equivalent statistics.

## Approval gates for analysis
- Each six-jurisdiction figure has linked primary source.
- All comparison variables have matched reference dates and compatible definitions.
- Denominators and missing data are documented.
- Descriptive summary first; inferential analysis requires independent observations and an explicit test justification.
