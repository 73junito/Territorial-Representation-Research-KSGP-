# Citation guidance (provisional)

This is **not** a final independently verified APA 7 bibliography. Academic reviewers should check official document title pages, dates, release versions and URLs before publication.

## Cite original data products
- U.S. Census Bureau, 2020 Island Areas Census Demographic Profile Summary File, official technical documentation and four Area Table Matrix workbooks.
- U.S. Census Bureau, 2019 ACS/PRCS one-year Detailed Tables and Summary Files, D.C. and Puerto Rico.
- U.S. Census Bureau, 2016–2020 ACS/PRCS five-year Detailed Tables and Summary Files.
- U.S. Census Bureau, *Understanding and Using American Community Survey Data: What All Data Users Need to Know* (2020), Chapter 8, for margin-of-error methods.

For each reported observation specify Census product, jurisdiction, reference period, exact table field, source URL, estimate denominator, units and uncertainty status. Island Areas reference codes include DPxx0200001, DPxx0510001, DPxx0630001 and DPxx0900001/0002. ACS/PRCS component tables include B15003, B23025, B19013 and B17001.

The calculated percentage MOEs are **method-derived approximations**, not independently downloaded official profile MOEs. Refer readers to the Phase 2H reconciliation matrix and its BLOCKED status.
